# orchestra-mcp/pack-desktop

Desktop application skills for Wails and macOS integration

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-desktop
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-desktop")
```

## Contents

| Type | Names |
|------|-------|
| Skills | wails-desktop, macos-integration |
| Agents | platform-engineer, widget-engineer |
| Hooks | None |
